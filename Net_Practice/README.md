# Net_Practice

This project is present here: https://github.com/Diogo-Serra/Net_Practice

---

NetPractice is a 42 curriculum networking project focused on IPv4 subnetting and routing. It consists of repairing progressively complex simulated networks in a browser-based training interface - correcting IP addresses, subnet masks, default gateways, and routing table entries across 10 levels - supported by a written README and a technical study guide on addressing, CIDR, gateways, routing, and the OSI model.
